Главная страница: index.html

Публикация на GitHub Pages:
1. Распакуйте архив.
2. Загрузите ВСЕ файлы и папки из архива в корень репозитория GitHub.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку main и папку /(root), затем Save.

Важно: не переименовывайте index.html и не перемещайте страницы отдельно.
Все HTML-страницы, CSS, JavaScript и favicon.svg должны лежать рядом в корне репозитория.

В этой версии сохранены авторские страницы, тексты и изображения планет. Изображения планет статичны: их текстуры не вращаются и не двигаются.
